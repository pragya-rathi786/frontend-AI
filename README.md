# Frontend AI Capstone

Capstone project for the FlyRank AI Internship Frontend AI Engineering track, built with React, TypeScript, Vite, and AI-assisted development.

## Features
- Feature one (e.g. add and delete tasks)
- Feature two (e.g. responsive layout)
- Feature three (e.g. AI-generated task suggestions)

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Claude Code for AI-assisted development

## Getting Started

### Prerequisites
- Node.js (LTS)
- Git

### Installation
```bash
git clone https://github.com/pragya-rathi786/frontend-ai-capstone.git
cd frontend-ai-capstone
npm install
npm run dev
```
